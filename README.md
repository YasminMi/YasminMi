## Featured Work

### 🏆 Zera.ai — 1st Place, Batalha de Agentes Itaú × Google 2026

<a href="https://github.com/YasminMi/zera.ai-itau">
 <img src="https://github.com/YasminMi/zera.ai-itau/blob/main/docs/img/banner.jpg?raw=true" alt="Zera.ai — 1st Place, Batalha de Agentes Itaú × Google 2026" width="70%"/>
</a>

AI agent for debt renegotiation, built in a two-day hackathon promoted by Itaú in partnership with Google Cloud and Santo Digital. The agent reads the customer's banking history, computes what fits the monthly budget through a deterministic engine and only proceeds after explicit customer confirmation.

**Design principle:** the LLM explains — it never does the math.

- **Data:** 467K real transactions from 1,000 customers, segmented with k-means in BigQuery ML.
- **Architecture:** Google ADK + Gemini on Vertex AI, human-in-the-loop confirmation, three-layer guardrails and 101 automated tests.
- **Delivery:** FastAPI + React deployed as a single service on Google Cloud Run, following an Agent Development Life Cycle — contract first, behavior-driven tests, evaluation on real data, observability.

**My role:** RAG and AI guardrails — consent validation, PII redaction, adversarial payload detection, off-topic handling and blocking of unsupported numerical claims.

→ [Repository, C4 architecture and engineering decisions](https://github.com/YasminMi/zera.ai-itau)

### AVA — Enterprise AI Platform for Technical & Regulatory Knowledge

Corporate platform that gives teams grounded, verifiable answers over technical and regulatory documents. I work across the entire system, from product architecture to production.

- **Retrieval:** hybrid search with FAISS + BM25, embeddings, reranking and retrieval optimization.
- **Grounding & evaluation:** evidence validation, evaluation datasets and systematic answer validation.
- **Ingestion:** document processing and OCR pipelines feeding a managed knowledge base.
- **Platform:** Python / FastAPI backend, Vue.js frontend, PostgreSQL, authentication and access control, deployed on Railway.

`Python` · `FastAPI` · `Vue.js` · `PostgreSQL` · `RAG` · `FAISS` · `BM25` · `Reranking` · `LLMs`

> Production code is proprietary. [ava-rag-backend](https://github.com/YasminMi/ava-rag-backend) documents the architecture and engineering decisions without exposing confidential business logic or data.
